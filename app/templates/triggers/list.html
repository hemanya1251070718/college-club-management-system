# Trigger Name Timing & Table Enforced Business Rule Live Test
1 trg_after_membership_insert_sync_count Member 1 AFTER INSERT Memberships When a student joins a club with status 'Active', Clubs.member_count automatically increments by 1 in real time. Enroll Member
2 trg_after_membership_delete_sync_count Member 1 AFTER DELETE Memberships When an active membership is deleted, Clubs.member_count automatically decrements by 1 directly in the base table. Delete Member
3 trg_prevent_multiple_presidents Member 2 BEFORE INSERT Memberships Enforces Club Bylaws: Aborts transaction via SIGNAL SQLSTATE '45000' if an attempt is made to insert a second active President for the same club. Test 2nd President
4 trg_adjust_member_count_on_status_change Member 2 AFTER UPDATE Memberships When a member's status is toggled between Active and Inactive (leave/reinstatement), Clubs.member_count is automatically incremented or decremented. Toggle Status
5 trg_prevent_registration_for_completed_event Member 3 BEFORE INSERT EventRegistrations Rejects retrospective registrations for events that are already marked 'Completed' or 'Cancelled'. Test on Events
6 trg_verify_feedback_registration Member 3 BEFORE INSERT Feedback Authenticity assurance: Intercepts event feedback submissions and verifies via cross-table check that the student was registered for that event. Test Feedback
7 trg_auto_progress_event_on_attendance Member 4 AFTER UPDATE EventRegistrations When attendee status is marked 'Attended' at the check-in desk, if the event was 'Planned', it automatically flips to 'Ongoing'. Mark Attendance
8 trg_auto_create_club_profile Member 4 AFTER INSERT Clubs Zero-config provisioning: When a new club is created, automatically provisions baseline profile row with institutional email and Instagram handle in ClubProfile. Create Club
