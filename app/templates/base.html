CREATE TRIGGER trg_after_membership_insert_sync_count
AFTER INSERT ON Memberships
FOR EACH ROW
BEGIN
    IF NEW.status = 'Active' THEN
        UPDATE Clubs
        SET member_count = member_count + 1
        WHERE club_id = NEW.club_id;
    END IF;

Ben Shneiderman's 8 Golden Rules of Interface Design

Every interface, workflow, form, and trigger in ClubHub has been audited and refactored to comply with Ben Shneiderman's 8 Golden Rules. Below is the executive implementation mapping:

1. STRIVE FOR CONSISTENCY COMPLIANT

Centralized design tokens (tokens.css), uniform 4-state buttons, standardized 56px table rows, consistent modal architecture (Header/Body/Footer), and single terminology across all 8 modules.

2. SEEK UNIVERSAL USABILITY (ENABLE SHORTCUTS) COMPLIANT

Full keyboard navigation with visible :focus-visible rings, modal focus trapping, global shortcuts (/ search, ? shortcuts guide, Esc dismiss), WCAG AA contrast, and reduced-motion support.

3. OFFER INFORMATIVE FEEDBACK COMPLIANT

Immediate UI response on every interaction: Google Pay rainbow confirmation animation on auth, live Cloud SQL socket heartbeat, inline role badges, and accessible screen-reader toast notifications (aria-live).

4. DESIGN DIALOGS TO YIELD CLOSURE COMPLIANT

All multi-step forms (Charters, Enrolment, Events) feature clear progression badges, pre-submission review summaries, and distinct completion confirmation states with explicit next actions.

5. PREVENT ERRORS COMPLIANT

Real-time regex email role detection, client-side date/capacity validation, destructive action safeguards, and helpful human-readable error messages explaining what went wrong and how to fix it.

6. PERMIT EASY REVERSAL OF ACTIONS COMPLIANT

Pre-destruction confirmation modals for all deletes, clear Cancel buttons returning to list states, reversible membership status toggles (Active ↔ Inactive), and undoable form edits.

7. KEEP USERS IN CONTROL (INTERNAL LOCUS) COMPLIANT

Top-right 1-Click Guest Evaluator button for unconstrained demonstration, explicit role persona switcher, easily dismissible non-blocking drawer, and clear system status controls.

8. REDUCE SHORT-TERM MEMORY LOAD COMPLIANT

Universal breadcrumb navigation trails on all inner pages, inline SQL code boxes for triggers and stored procedures, automatic form draft persistence in localStorage, and contextual help tooltips.
