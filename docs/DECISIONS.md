# Architectural & Technical Decisions Log

| Decision ID | What Was Decided | Why | Alternatives Considered |
|---|---|---|---|
| **DEC-001** | Use existing `Club_Management_System_BASE.sql` schema instead of creating a dummy schema. | It contains real student/club data from the user's DBMS course, foreign key relationships, a view (`ClubSummary`), and stored procedures (`GetStudentClubs`, `sp_audit_club_counts`). This makes the interview defense authentic and impressive. | Proposing a simplified 4-table toy schema (rejected because real schema already exists and is well-designed). |
| **DEC-002** | Target MySQL 8.0 on Cloud SQL. | The local database running on Windows is MySQL Community Server 8.0.46, and the schema script targets MySQL 8.x (`ENGINE=InnoDB`, `CHECK` constraints, `DELIMITER`). Matching engine versions eliminates dialect incompatibilities between local dev and cloud. | Cloud SQL PostgreSQL or MySQL 5.7 (rejected to preserve exact schema compatibility). |
| **DEC-003** | Use triggers for automated member count maintenance (`trg_increase_member_count` / `trg_decrease_member_count`). | The schema defines `member_count` on `Clubs` and drops triggers for it in `Club_Management_System_BASE.sql`. Using automated triggers directly demonstrates DB trigger functionality required by the project brief and syncs with `sp_audit_club_counts`. | Application-level counting in Python or scheduled batch sync (rejected; database-level trigger is required by task). |
| **DEC-004** | Use PyMySQL with DictCursor over an ORM (like SQLAlchemy). | Pure Python, lightweight, eliminates compilation issues across Windows and Linux, and keeps SQL queries 100% transparent and explicit for an interview defense. | SQLAlchemy ORM (adds abstraction overhead and hides raw SQL queries interviewers ask about). |
| **DEC-005** | Implement dual-mode DB connector in `app/db.py`. | Seamlessly switches between TCP socket for local development and Unix Domain Socket (`/cloudsql/...`) for Cloud Run. Eliminates need for different codebases between local and cloud. | Separate database connector modules or conditional imports (adds complexity). |
| **DEC-006** | Enforce parameterized queries everywhere (`cursor.execute(sql, (params,))`). | Completely neutralizes SQL injection vulnerabilities. Fulfills strict cloud security requirement. | String interpolation or f-strings (strictly insecure; immediate red flag in interviews). |
